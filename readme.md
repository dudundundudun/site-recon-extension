# ⚡ One-Button Site Recon for AI (v1.4.0)

> **— Вот скажи мне, американец, в чём сила? Разве в обфускации?**
>
> Вот и бэкендер говорит, что в обфускации, в Cloudflare и кривых классах Tailwind. А я думаю, что сила — в правде. У кого реальные селекторы, перехваченные `fetch`-запросы и дампы `window` — тот и сильней.

**One-Button Site Recon for AI** — это легковесное браузерное расширение для Google Chrome (Manifest V3), созданное по принципу «одной большой кнопки». Открыл сайт, нажал кнопку — и в твоем буфере обмена уже лежит полный технический слепок страницы, готовый к отправке в Claude, Gemini, DeepSeek или GPT для написания парсеров, юзерскриптов и браузерных дополнений с первой попытки.

Больше не нужно вручную ковырять вкладку Network в DevTools, копировать cURL по одному запросу или объяснять нейросети на пальцах, в каком именно `div` лежит читалка манги или видеоплеер.

## 🆕 Что нового в v1.4.0

* **Усиленная безопасность и маскировка секретов** — скрываются значения чувствительных полей (`password`, `email`, `tel`, `hidden`, OTP/карты/токены), секретные query-параметры в URL, расширенный список авторизационных заголовков, `URLSearchParams` и секреты внутри встроенных JSON-скриптов.
* **Бережная работа с памятью и приватностью** — `interceptor.js` не клонирует SSE-потоки, `opaque`-ответы и ответы тяжелее 2 МБ, а обмен сообщениями между скриптами работает строго в пределах `location.origin` и только в режиме записи.
* **Надёжная запись сессии** — в `background.js` добавлена очередь записей (`writeQueue`), чтобы параллельные события не перетирали друг друга; остановка записи теперь безопасно работает даже с системных вкладок (`chrome://`, `about:`), сохраняя собранный `sessionFlow`.
* **Без лишней нагрузки и раздутых отчётов** — фоновый таймер навигации в `recorder_bridge.js` включается только во время записи, а тяжёлые отчёты автоматически ужимаются до бюджета ~180 КБ с сохранением валидного JSON.
* **Поддержка открытого Shadow DOM** — разведчик заглядывает внутрь открытых `shadowRoot` глубиной до 3 уровней и помечает найденные узлы флагом `inShadowDom`.

## 🎯 Что собирает разведчик за один клик

Расширение работает напрямую в контексте страницы (`MAIN` world) с момента `document_start`, поэтому видит ровно то же, что и сам сайт:

* **Сетевой перехват (`Fetch`, `XMLHttpRequest` и `WebSocket`)** — фиксирует живые API-запросы, методы, статус-коды, отправленные заголовки, тела запросов и превью текстовых/JSON/XML/m3u8 ответов, автоматически отсеивая аналитический шум и маскируя секреты.
* **Ресурсы из `Performance API`** — выцепляет фоновые обращения к `/api/`, `graphql`, `.json`, а также медиа-потоки (`.m3u8`, `.mpd`, `.mp4`), которые проскочили мимо стандартных хуков.
* **Технологический стек и глобальные переменные `window`** — определяет фреймворки (`React`, `Next.js`, `Vue`, `Nuxt`, `Angular`, `jQuery`, `Shopify`), находит нестандартные глобальные объекты в `window` (скрытые конфиги, стейты плееров) и вытаскивает встроенные JSON-скрипты (`#__NEXT_DATA__`, `application/ld+json`).
* **Чистый скелет DOM, открытый Shadow DOM и интерактивные узлы** — строит компактное дерево контейнеров с `data-*` атрибутами (включая открытые `shadowRoot` до 3 уровней) и собирает реальные CSS-селекторы кнопок, форм, инпутов и ссылок.
* **Медиа-контейнеры и ассеты** — индексирует теги `<img>`, `<canvas>`, `<picture>`, `<video>` и `<iframe>` вместе с их `src`, `data-src`, `srcset`, размерами и родительскими селекторами.
* **Локальные хранилища и метаданные `Cookies`** — снимает ключи и замаскированные превью значений из `localStorage` и `sessionStorage`, а также собирает список имен и флагов (`httpOnly`, `secure`) всех кук домена через `chrome.cookies`.

## 🕹️ Интерфейс: ничего лишнего

Никаких перегруженных панелей с сотней вкладок. Внутри попапа только то, что нужно для дела:

1. **🚀 СДЕЛАТЬ ПОЛНЫЙ СЛЕПОК САЙТА** — одна большая кнопка. Сканирует страницу, формирует отчет и **автоматически копирует готовый промпт для ИИ в буфер обмена**.
2. **🔴 Записать флоу (переходы, клики, API)** — включает запись пользовательской сессии с бейджем `REC` (переживает переходы и перезагрузки на том же домене), а по повторному нажатию останавливает запись и собирает итоговый отчет с `sessionFlow`.
3. **📋 Промпт ИИ** — копирует полный отчет в формате Markdown с системной инструкцией для LLM и вложенным JSON-блоком.
4. **{ } JSON** — копирует чистый необработанный JSON-слепок для программного анализа или локальных скриптов.
5. **💾 Скачать** — сохраняет готовый файл отчета `site-recon-<domain>-<timestamp>.md` на диск.

## 🛠️ Установка за 30 секунд

Расширение не требует сборки, `npm install` или вебпаков — чистый Vanilla JS.

1. Скачай архив релиза или клонируй репозиторий:

   ```bash
   git clone https://github.com/dudundundudun/one-button-site-recon.git
   ```

2. Открой браузер Chrome и перейди по адресу `chrome://extensions`.
3. Включи переключатель **Режим разработчика** (**Developer mode**) в правом верхнем углу.
4. Нажми **Загрузить распакованное расширение** (**Load unpacked**) и выбери папку `site-recon-extension` с файлами проекта.

## 🤖 Как кормить отчет нейросети (Workflow)

1. Зайди на нужный сайт, пролистай страницу или открой нужный раздел (чтобы отработали ленивая подгрузка и `fetch`-запросы).
2. Кликни по иконке расширения и нажми **«🚀 СДЕЛАТЬ ПОЛНЫЙ СЛЕПОК САЙТА»** (или запиши многошаговый сценарий кнопкой **«🔴 Записать флоу»**).
3. Открой чат с ИИ, нажми `Ctrl + V` и допиши в конце свою задачу, например:

   > *«Вот слепок сайта. Напиши мне расширение / Python-парсер на `httpx`, который вытаскивает все картинки главы в оригинальном качестве и складывает их в отдельную папку по названию тайтла».*

Нейросеть сразу увидит точные эндпоинты, заголовки, глобальные объекты `window` и селекторы контейнеров — без галлюцинаций и угадывания классов.

## 📁 Структура проекта

| Файл | Назначение |
| ----- | ----- |
| `manifest.json` | Конфигурация расширения Manifest V3 (`v1.4.0`), права доступа и регистрация скриптов |
| `background.js` | Service Worker с очередью `writeQueue` для надёжного хранения записанной сессии в `chrome.storage.session` |
| `interceptor.js` | Скрипт раннего перехвата (`document_start`, `MAIN` world), оборачивающий `fetch`, `XMLHttpRequest` и `WebSocket` с маскировкой секретов |
| `recorder_bridge.js` | Мост в `ISOLATED` world, пересылающий клики, переходы и сетевые события во время записи |
| `popup.html` | Компактный интерфейс в темной теме с кнопками сканирования, записи флоу и экспорта |
| `popup.js` | Логика инспекции DOM/Shadow DOM, `Performance API`, `window`, хранилищ, бюджета отчёта (~180 КБ) и генерации отчета для ИИ |
| `README.md` | Документация, установка и история изменений |
