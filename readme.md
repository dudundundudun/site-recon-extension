# ⚡ One-Button Site Recon for AI






> **— Вот скажи мне, американец, в чём сила? Разве в обфускации?**  
> Вот и бэкендер говорит, что в обфускации, в Cloudflare и кривых классах Tailwind. А я думаю, что сила — в правде. У кого реальные селекторы, перехваченные `fetch`-запросы и дампы `window` — тот и сильней.

**One-Button Site Recon for AI** — это легковесное браузерное расширение для Google Chrome (Manifest V3), созданное по принципу «одной большой кнопки». Открыл сайт, нажал кнопку — и в твоем буфере обмена уже лежит полный технический слепок страницы, готовый к отправке в Claude, Gemini, DeepSeek или GPT для написания парсеров, юзерскриптов и браузерных дополнений с первой попытки.

Больше не нужно вручную ковырять вкладку Network в DevTools, копировать cURL по одному запросу или объяснять нейросети на пальцах, в каком именно `div` лежит читалка манги или видеоплеер.

## 🎯 Что собирает разведчик за один клик

Расширение работает напрямую в контексте страницы (`MAIN` world) с момента `document_start`, поэтому видит ровно то же, что и сам сайт:

* **Сетевой перехват (`Fetch` и `XMLHttpRequest`)** — фиксирует живые API-запросы, методы, статус-коды, отправленные заголовки, тела запросов и превью текстовых/JSON/XML/m3u8 ответов.
* **Ресурсы из `Performance API`** — выцепляет фоновые обращения к `/api/`, `graphql`, `.json`, а также медиа-потоки (`.m3u8`, `.mpd`, `.mp4`), которые проскочили мимо стандартных хуков.
* **Технологический стек и глобальные переменные `window`** — определяет фреймворки (`React`, `Next.js`, `Vue`, `Nuxt`, `Angular`, `jQuery`, `Shopify`), находит нестандартные глобальные объекты в `window` (скрытые конфиги, стейты плееров, ключи API) и вытаскивает встроенные JSON-скрипты (`#__NEXT_DATA__`, `application/ld+json`).
* **Чистый скелет DOM и интерактивные узлы** — строит компактное дерево контейнеров с `data-*` атрибутами и собирает реальные CSS-селекторы кнопок, форм, инпутов и ссылок.
* **Медиа-контейнеры и ассеты** — индексирует теги `<img>`, `<canvas>`, `<picture>`, `<video>` и `<iframe>` вместе с их `src`, `data-src`, `srcset`, размерами и родительскими селекторами (идеально для написания загрузчиков манги, галерей и видео).
* **Локальные хранилища и метаданные `Cookies`** — снимает ключи и превью значений из `localStorage` и `sessionStorage`, а также собирает список имен и флагов (`httpOnly`, `secure`) всех кук домена через `chrome.cookies`.

## 🕹️ Интерфейс: ничего лишнего

Никаких перегруженных панелей с сотней вкладок. Внутри попапа только то, что нужно для дела:

1. **🚀 СДЕЛАТЬ ПОЛНЫЙ СЛЕПОК САЙТА** — одна большая кнопка. Сканирует страницу, формирует отчет и **автоматически копирует готовый промпт для ИИ в буфер обмена**.
2. **📋 Промпт ИИ** — копирует полный отчет в формате Markdown с системной инструкцией для LLM и вложенным JSON-блоком.
3. **{ } JSON** — копирует чистый необработанный JSON-слепок для программного анализа или локальных скриптов.
4. **💾 Скачать** — сохраняет готовый файл отчета `site-recon-<domain>-<timestamp>.md` на диск.

## 🛠️ Установка за 30 секунд

Расширение не требует сборки, `npm install` или вебпаков — чистый Vanilla JS.

1. Скачай или клонируй этот репозиторий:
   ```bash
   git clone https://github.com/dudundundudun/one-button-site-recon.git
   ```
2. Открой браузер Chrome и перейди по адресу `chrome://extensions`.
3. Включи переключатель **Режим разработчика** (**Developer mode**) в правом верхнем углу.
4. Нажми **Загрузить распакованное расширение** (**Load unpacked**) и выбери папку с файлами проекта.

## 🤖 Как кормить отчет нейросети (Workflow)

1. Зайди на нужный сайт, пролистай страницу или открой нужный раздел (чтобы отработали ленивая подгрузка и `fetch`-запросы).
2. Кликни по иконке расширения и нажми **«🚀 СДЕЛАТЬ ПОЛНЫЙ СЛЕПОК САЙТА»**.
3. Открой чат с ИИ, нажми `Ctrl + V` и допиши в конце свою задачу, например:
   > *«Вот слепок сайта. Напиши мне расширение / Python-парсер на `httpx`, который вытаскивает все картинки главы в оригинальном качестве и складывает их в отдельную папку по названию тайтла».*

Нейросеть сразу увидит точные эндпоинты, заголовки авторизации, глобальные объекты `window` и селекторы контейнеров — без галлюцинаций и угадывания классов.

## 📁 Структура проекта

| Файл | Назначение |
| :--- | :--- |
| `manifest.json` | Конфигурация расширения Manifest V3, права доступа и регистрация хука в `MAIN` world |
| `interceptor.js` | Скрипт раннего перехвата (`document_start`), оборачивающий `window.fetch` и `XMLHttpRequest` |
| `popup.html` | Компактный интерфейс в темной теме с одной главной кнопкой и тремя кнопками экспорта |
| `popup.js` | Логика инспекции DOM, `Performance API`, `window`, хранилищ и генерации отчета для ИИ |
